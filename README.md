
# MMA3001 — Pork Rasher Packaging Defect Detection

## Project Overview

This project investigates the automated detection and localisation of packaging defects in pork rasher trays using computer vision and numerical methods.

The project is developed for MMA3001 — Numerical Methods and Machine Learning at Monash University.

## Engineering Problem

Manual inspection of food packaging can be time-consuming and inconsistent. This project aims to investigate a computational approach for identifying visible packaging defects in RGB images.

The intended outputs include:
- Defect class labels
- Bounding-box locations
- Detection confidence scores

## Dataset

**Dataset:** Pork Rasher Error-Packaging, Version 4

**Source:** https://universe.roboflow.com/hello-2aqe0/pork-rasher-error-packaging/dataset/4

**Dataset licence:** CC BY 4.0

The dataset contains 3,549 images with five annotated defect classes.
